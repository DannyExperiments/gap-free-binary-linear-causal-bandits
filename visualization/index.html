How to read the example

The reference model is shown for explanation. A learner sees sampled node values and compares the predictions of its remaining models. Setting X to one clamps X, while the disagreement in Z and Y gives two coordinates for comparing the models. In this example the reward prediction error is 0.14 = 0.22 + 0.20 × (−0.40), where 0.22 is the fitted reward-row residual evaluated on the reference means.
